3. 毎月やること
4ステップです
1
動画ができたら、2つ入力する

投稿計画表の 動画アーカイブ タブを開いて、その動画の行に入れます。

どの列何を入れる
J列「収録方法」プルダウンから選びます（実写 / AI音声）。手で打った文字は入りません
K列「稼働日」実写だけ入れます。撮影した日を、出てくるカレンダーから選びます
AI音声は入れなくて大丈夫です。公開日が自動で入ります

実写の「稼働日」は公開日ではありません。ここで「何月分の支払いか」が決まります。 月をまたいで公開された動画は、撮った月のぶんとして計算されます。

AI音声は「稼働日＝公開日」です。収録方法で AI音声 を選んだ瞬間に自動で入ります。 書き換えても元に戻ります（演者が収録していないので、稼働した日を決めようがないためです）。

2
月末に、年と月を入れる

請求集計 タブを開いて、B1に年（例 2026）、B2に月（例 8）を入れるだけです。

本数・単価・金額が自動で出ます。ほかのセルは数式なので触らないでください。

3
いちばん下の「見張り」2つが 0 か確認する

どちらも 0 なら、そのまま進めて大丈夫です。0 でなければ下の「4. 締める前の確認」を見てください。

4
演者に本数と金額を伝える

実写とAI音声は単価が違うので、分けて伝えます。金額は請求集計に出ているものをそのまま伝えます。

例：「今月は実写3本、AI音声2本で 8,000円です」

4. 締める前の確認
この2つが 0 でないときは、支払いに漏れがあります
表示0 でないときの意味どうするか
稼働日が空の行 収録方法は入っているのに稼働日が入っていない動画があります。その本数は請求から抜けています 動画アーカイブの K列を埋める
単価マスタに無い演者 あさひさん・りいさん以外の人に稼働が入っています 入力ミスなら直す。本当に支払う人なら単価マスタに行を足す
5. 困ったとき
よくあるつまずき
本数が 0 のまま出てこない
稼働日が「日付」になっていない可能性が高いです。 文字として入っていると集計されません（エラーも出ません）。 セルを選んで右寄せに表示されていれば日付、左寄せなら文字です。 カレンダーから選べば必ず日付になります。
単価を変えたい
単価マスタ タブの C列（単価）だけを直します。 ここ1か所を直せば、請求集計にも自動で反映されます。ほかは触らないでください。
支払う人が増えた
2か所に足します。 ① 単価マスタ に「演者／収録方法／単価」の行を追加（実写とAI音声の2行） ② 請求集計 の表にもその人の行を追加。 ①だけだと集計に出てきません。
先月いくら払ったか見たい
請求集計の年と月を先月に戻せば見られます。 ただしそのあと動画アーカイブを編集すると、先月の金額も変わります。 記録として残したいときは、締めた時点で金額をどこかに控えておいてください。
1本の中で実写とAI音声が混ざっている
そういう動画は無い前提で作っています。 もし出てきたら、勝手に決めずに運営者に確認してください。
